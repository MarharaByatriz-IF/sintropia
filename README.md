# SintropIA

> Jogo 2D de exploração e aventura sobre recuperação ambiental e inteligência artificial.

## Sobre o projeto

SintropIA é um jogo 2D de exploração ambientado em um mundo pós-colapso ambiental. O jogador acompanha uma inteligência artificial responsável por explorar regiões degradadas e contribuir para a recuperação dos ecossistemas.

Durante a jornada, o jogador encontra diferentes ambientes, recursos e situações que envolvem decisões relacionadas à recuperação ambiental.

## Objetivo

O projeto busca apresentar, de forma interativa, questões relacionadas à preservação ambiental, recuperação de áreas degradadas e uso da tecnologia na busca por soluções para problemas ambientais.

## Características

- Exploração de ambientes 2D;
- Recuperação de regiões degradadas;
- Elementos de aventura e exploração;
- Sistema de decisões;
- Interface e elementos visuais próprios;
- Ambientação pós-colapso ambiental.

## Tecnologias

- **GDScript**
- **LibreSprite**
